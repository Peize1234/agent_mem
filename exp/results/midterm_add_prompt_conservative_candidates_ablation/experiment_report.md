## 事实归纳

- 三个候选在两种 Query 检索方式下的 Micro/Macro Top5 均低于原 Production。
- 三个候选共同 demote 的 Gold：原始问题直接检索 8 个；上下文引用解析后检索 6 个。
- 候选之间并非完全同错：有序候选对能保留或救回另一候选丢失的 Gold 数介于 3 和 7。
- 对所有 demoted movement 行汇总，RELATION anchors 新增 21、丢失 40；JUDGMENT 新增 28、丢失 60；DEPENDENCY 新增 15、丢失 26。
- 同一批 demoted movement 中，INDICATOR anchors 新增 44、丢失 18；NUMBER anchors 新增 513、丢失 385。这说明严重下降不能只用摘要长度或信息总量解释。
- 实际 512-token 右截断 Page 数：Production 76；最小改动 109；多检索入口 92；任务 + 证据链 123。formatter 未变，但更长内容会让末尾 User 字段更常被截断。
- 与 Production keywords 完全同序的 Page 数：最小改动 50；多检索入口 33；任务 + 证据链 55（总 Page 333）。
